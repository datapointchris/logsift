# Guides

Task-shaped instructions for using logsift on real commands and logs. Each guide assumes logsift is
already installed.

## Documentation

- [Structured Logging](structured-logging.md) — How to write a script whose output logsift can read, with Python, Bash, Node and Make examples
- [Custom Patterns](custom-patterns.md) — Adding a TOML pattern file under `~/.config/logsift/patterns`, testing it, and how priority resolves overlaps
- [Process Monitoring](monitoring.md) — Naming and caching monitored runs, what the exit codes mean, and piping a run into jq or tee
